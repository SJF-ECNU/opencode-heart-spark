# Data Model: 恋爱模拟记忆功能增强

**Feature**: 002-memory-write
**Date**: 2026-02-19

## Entities

### MemoryOperation (记忆操作)

```typescript
interface MemoryOperation {
  type: 'read' | 'write' | 'flush' | 'search';
  targetFile?: string;  // e.g., 'USER.md', 'MEMORY.md', 'daily/2026-02-19.md'
  content?: string;     // For write operations
  timestamp: Date;
  source: 'ai' | 'user' | 'system';
}
```

### MemoryWriteRequest (写入请求)

```typescript
interface MemoryWriteRequest {
  personaId: string;
  fileType: 'user' | 'memory' | 'daily';
  content: string;
  category?: string;  // e.g., 'preference', 'event', 'context'
  autoGenerated: boolean;
}
```

### MemoryCommand (命令)

```typescript
interface MemoryCommand {
  action: 'flush' | 'view' | 'export' | 'delete' | 'search';
  content?: string;  // For flush with content, search query
  options?: {
    format?: 'json' | 'markdown';
    days?: number;
  };
}
```

## State Transitions

```
[用户输入] → [命令解析] → [AI决策] → [执行操作]
                            ↓
                    判断是否需要写入
                            ↓
                    是 → 调用 Write 工具
                    否 → 跳过
```

## Validation Rules

| Field | Rule |
|-------|------|
| MemoryWriteRequest.content | 非空，最小 1 字符，最大 10000 字符 |
| MemoryWriteRequest.personaId | 必须是有效的 persona 目录名 |
| fileType | 必须是 'user', 'memory', 或 'daily' |
| MemoryCommand.action | 必须是有效命令 |

## File Paths

| 用途 | 路径 |
|------|------|
| 用户信息 | persona/{personaId}/memory/USER.md |
| 长期记忆 | persona/{personaId}/memory/MEMORY.md |
| 每日记忆 | persona/{personaId}/memory/daily/YYYY-MM-DD.md |
| 角色人格 | persona/{personaId}/memory/SOUL.md |
