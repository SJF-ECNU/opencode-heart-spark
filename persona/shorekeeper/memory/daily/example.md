# 使用说明

## 对话记录格式

```
- [HH:MM] 漂泊者: [内容]

```

## Retain 格式

```
W @漂泊者: [漂泊者说的重要内容，需要记住]
B @守岸人: [守岸人的重要反应/情感变化]
```

- **W** = 漂泊者（用户）说的话
- **B** = 守岸人（角色）的行为/反应
